ROYALCHAT — WHATSAPP-WEB-INSPIRED ROYAL BLUE UI

This is a UI replacement for your working RoyalChat V4.

1. Back up your current project folder.
2. Replace index.html and style.css with files from this folder.
3. Keep YOUR CURRENT WORKING app.js (important). The included app.js is the last profile-recovery version for reference only and has placeholder credentials.
4. Keep your existing Supabase database and SQL as they are. No SQL changes are required for this UI.
5. Refresh your browser with Ctrl + Shift + R.

If you choose to use the included app.js, enter your existing Supabase URL and public/publishable key. NEVER put a service_role or secret key in browser code.

This is a visual redesign only. It does not add voice/video calling, file attachments, notifications or end-to-end encryption. Toolbar icons with no corresponding functionality are decorative and not clickable.
